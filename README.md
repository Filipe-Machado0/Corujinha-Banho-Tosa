# Corujinha Banho & Tosa 🐾

Website institucional e responsivo desenvolvido para a **Corujinha Banho & Tosa**, localizada em Angatuba - SP.

## 🚀 Tecnologias Utilizadas
- **HTML5** semântico e otimizado para SEO
- **CSS3** moderno com design system proprietário (paleta baseada na fachada Azul Royal)
- **JavaScript (Vanilla)** para interatividade e animações de scroll reveal
- **Ícones Vetoriais SVG** de alta precisão

## 📋 Recursos do Projeto
- **Zero Emojis**: Design limpo e institucional
- **Avaliações do Google**: Seção de depoimentos no padrão oficial de reputação
- **Catálogo de Serviços**: Cards estruturados de Banho e Tosa com botão direto para WhatsApp com mensagem pré-definida
- **Botão Flutuante de Contato**: Azul Royal com radar pulse effect
- **Localização**: Mapa integrado via Google Maps
- **100% Responsivo**: Otimizado para desktop, tablets e smartphones
